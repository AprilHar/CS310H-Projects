# CS310H-Projects
Place to store code from Unreal Engine for CS310H Labs

## HW1 Tasks & Video
### Tasks
1. Create a new project. (20 Pts)
   - Use the FPS template and load the starter assets
2. Create a custom spinning object to the level and add at least three to the level (20 Pts)
   - This should have a static mesh that automatically spins in place when the level loads
   - You will need to have a total of three of them in your level
3. Print out a string when the player presses a button on the keyboard (20 Pts)
   - Link a button press event that prints out a message whenever the key is pressed
4. Create an object that lights on fire whenever the player collides with it (20 Pts)
   - Using a Hit event set a fire effect active whenever the player touches the object
   - This effect should be a child of the main static mesh object
5. Add a light switch that turns a light on or off (20 Pts)
   - When the player runs over the object it should toggle between the light being active or not
